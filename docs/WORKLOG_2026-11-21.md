### 3.1 代码

| 文件 | 改动 |
|---|---|
| `tools/hos_identity.py`（新增） | 最小 DICOM 头解析（支持 explicit/implicit VR、little/big endian），读取 `PatientID`；加载完整版收集表的 `住院号/姓名/影像信息`；`classify()` 输出配对状态；`KNOWN_OLD_IDS` 记录已核实旧号（10900337→编号 97） |

| `tools/build_hos_batch2_csv.py` | 第二批写入 `hospital_id`（取自 9.29 表），`ct_patient_id=mri_patient_id=hospital_id`，`pair_status=unverified`（该批原始 DICOM 已不存在，无法二次核验） |
| `tools/verify_hos_pairs.py`（新增） | 训练前自检：所有路径列必须存在；`pair_status` 不得为 `identity_conflict`；`ok` 行须满足 `ct_patient_id == hospital_id`；`--strict` 失败时非零退出 |

- `hospital_id`：收集表住院号

- `pair_status`：`ok` / `ok_old_id` / `typo_table` / `identity_conflict` / `no_image_id` / `no_table_id` / `unverified`
